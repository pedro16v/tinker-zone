privacy

tinker.zone is a public collaborative website that anyone can reshape by submitting a short, natural-language description of a change. This notice describes exactly what happens to what you type.

what we collect

  • The prompt you submit. Stored in our database (Supabase, Tokyo). Visible publicly in the time machine after a bake.
  • A hashed form of your IP address. Used only to rate-limit submissions (a SHA-256 hash; the original is not stored). Buckets reset as the hourly window rolls over.
  • Nothing else. No accounts, no tracking cookies, no analytics, no third-party trackers, no fingerprinting.

what happens to your prompt

  1. It's checked by a content-moderation model; unsafe content is rejected.
  2. If approved, a small declarative patch is generated and broadcast in real time to everyone currently viewing the site.
  3. Periodically, accumulated patches are baked into a permanent commit on the public source repository and a new version of the site is deployed. Every prompt that contributed to a bake appears in that bake's time-machine entry.

where the data lives

  • Source code (every version): github.com/pedro16v/tinker-zone, public.
  • Live + baked patches and prompts: Supabase, Tokyo region.
  • The site itself: Vercel, with one immutable URL per bake (listed in the time machine).

what we never do

  • We don't collect names, emails, accounts, locations, or device info.
  • We don't load any third-party trackers or analytics scripts. The site's strict Content-Security-Policy would block them at the browser anyway.
  • We don't share data with advertisers — there are none.

removing a submission

If you'd like a prompt or its baked effect removed, open an issue on the GitHub repo or contact the maintainer there. Because every change is in public git history, "removal" means a follow-up bake that undoes the previous one — the historical commit remains in git but won't be the current site.

changes to this notice

If this notice changes, the change goes through the same public commit as everything else. You can see the diff in git history.
